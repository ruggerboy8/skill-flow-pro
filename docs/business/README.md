# Business material

Client-facing and source material: correspondence, source content, and data
exports. Some of it is real product input, but none of it is project
documentation.

**Do not route an agent here.** `.claude/skills/_shared/doc-routing.md` never
points at `business/`. Nothing in this folder should be used to decide how to
change code.

Contents:

- `pro-moves-library-2026-06-25.csv`: export of the Pro Moves library, 2026-06-25
- `patient-journey-source.md`: source doc for the patient-journey audit framework
- `hospitality-principles-source.md`: source text of the three Alcan hospitality principles
- `sedation-calculator-hosting-email.md`: correspondence with the marketing agency

Uncommitted business drafts still sitting in a working copy under `docs/outbound/`
or `docs/reference/` belong here once they are committed. See the "Uncommitted
drafts" section of `docs/README.md`.
