# PRO MOVES — Branding package: what gets made, in what formats, for what

*Plain-language map of a proper small-brand package, scoped to what you actually need: the presentation, MyProMoves.com, and the app. Nothing agency-bloated.*

## The artifacts

**1 · The mark (logo icon).** The symbol that works alone — app icon, favicon, scrub pocket. This is the hard part and where the design congress runs.

**2 · The wordmark.** "PRO MOVES" set in Biondi Sans with deliberate spacing/weight decisions — not just typed, *drawn* (letterspacing, any custom cut details, how PRO relates to MOVES).

**3 · Lockups.** Mark + wordmark in horizontal and stacked arrangements; a co-brand lockup with Alcan (the sister-brand handshake); clear-space and minimum-size rules so nobody ever crowds or shrinks it into mush.

**4 · Color.** Pro Moves' palette as an extension of Alcan's: the inherited navy/blue/gray plus the brand's own accent decision(s); on-dark and on-light variants; one-color and reversed (white) versions of the mark.

**5 · Type rules.** One page: Biondi weights and cases for display vs. UI vs. labels.

**6 · The one-page brand sheet.** Everything above on a single reference page — the thing you hand Yuri, a printer, or a future contractor.

## Export formats, mapped to use

| Use | Files |
|---|---|
| **The presentation** | Mark + lockups as SVG and transparent PNG (@2x), tuned versions for the charcoal soundstage (`--floor #1A1D21`) |
| **MyProMoves.com** | Logo/wordmark SVG · favicon.ico (16/32/48) · favicon PNGs 16/32 · apple-touch-icon 180×180 · OG/social share image 1200×630 |
| **The app (PWA — phase 1 just shipped)** | PWA icons 192×192 + 512×512 + maskable variant · monochrome/notification glyph |
| **Print & merch later** | Vector masters (SVG + PDF); everything else derives from these |

All rasters derive from SVG masters — one source of truth, regenerate any size on demand. I produce every file above in this workspace and commit them to a `promoves-brand/exports/` folder.

## The process (our congress, adapted for iconography)

1. **Brief lock** — you edit/approve `brand-brief.md`. (You are here.)
2. **Mark congress** — five blind designer agents, distinct lenses (e.g., geometric monogram · Alcan-motif descendant · symbol-of-meaning · badge/craft tradition · wildcard), each *describes* a mark concept argued from the brief; light debate; jury shortlists.
3. **Render round** — shortlisted concepts drawn as real SVGs, presented as a grid: each shown at full size, at 16px, in mono, on dark and light. (A mark that dies at favicon size dies in this round — the grid makes it visible instantly.)
4. **Your reaction → refinement loops** — iterate on the chosen direction exactly like the deck frames: cheap rounds, visual reactions.
5. **Wordmark + lockups + color decision** — built around the locked mark.
6. **Package build** — all exports generated, brand sheet assembled, QA'd (real 16px screenshots, contrast checks), committed.
